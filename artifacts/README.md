# QA-Passed Artifacts

This directory stores applications, plugins, and other work that received an explicit QA PASS against the same source revision.

There is no required internal directory structure or manifest file. Use clear, collision-free names and keep the corresponding QA evidence in the ticket workflow.

Do not place PASS WITH ISSUES, FAIL, BLOCKED, or untested work here. Do not overwrite an existing approved artifact; revised work requires another QA cycle and a separately named artifact. Runtime contents are intentionally ignored by Git.
